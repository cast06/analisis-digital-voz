# Audios de referencia

Carpeta destinada a almacenar las grabaciones de audio etiquetadas para el reconocimiento automático de sílabas.

Sílabas iniciales:
- ma
- me
- mi
- pa
- pe
- pi

Formato recomendado: WAV PCM, mono, 16 bits y 16000 Hz.

Los audios se incorporarán conforme se realicen las grabaciones.
